# 场记工作台

先从稳定CLI/MCP发现当前启用包、能力摘要、Schema和同包方法，携带确切WorkRef与management_ref。先读固定作品、已有工程、成果和意见，不重复创建。

读取固定剧本 → 故事日和镜次 → 固定条次与观察 → 明确比较关系 → 处理不一致或未知 → 固定剪辑选择 → 新稿复核 → 场记本与接续。

场次故事日、场景、人物及镜次明确；条次记录只追加，mode分为人工记录与模拟。入出帧使用整数和精确有理帧率，不以毫秒近似代替时间码；不支持drop-frame时间码换算。连续性观察按角色或道具、类别、状态位置及入出分别记录；比较绑定确切两条和明确匹配项，缺观察返回unknown，允许作者明确有意变化并说明。剪辑选择固定当前场次镜次及条次组合摘要，剧本或镜次改变后旧选择待复核；不把选择记为宿主素材采用。已记录条次及旧观察不覆盖，新证据追加。

制作筹备拥有资源与计划，导演布景台拥有空间与机位，本包拥有条次及连续性记录；真实文件仍归宿主素材。没有实拍设备控制、自动识别穿帮、影片制作完成认证、外部发送或发布。

每阶段保存后回读修订；未知先get_operation，CAS保留输入。详细方法及反例见[流程](references/workflows.md)，实际动作见[操作地图](references/operations.md)。正文采纳、定稿、外发及费用独立决定。
