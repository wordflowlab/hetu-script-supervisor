# 创作流程与反例

把旧站两场戏按故事日整理。记录正反打两条里信封分别在哪只手，发现差异后保留有意换手的说明，再固定剪辑选择。

场次故事日、场景、人物及镜次明确；条次记录只追加，mode分为人工记录与模拟。入出帧使用整数和精确有理帧率，不以毫秒近似代替时间码；不支持drop-frame时间码换算。连续性观察按角色或道具、类别、状态位置及入出分别记录；比较绑定确切两条和明确匹配项，缺观察返回unknown，允许作者明确有意变化并说明。剪辑选择固定当前场次镜次及条次组合摘要，剧本或镜次改变后旧选择待复核；不把选择记为宿主素材采用。已记录条次及旧观察不覆盖，新证据追加。

制作筹备拥有资源与计划，导演布景台拥有空间与机位，本包拥有条次及连续性记录；真实文件仍归宿主素材。没有实拍设备控制、自动识别穿帮、影片制作完成认证、外部发送或发布。

## 固定接续

读取已有成果及全部必要来源，明确未读范围。新意见固定具体目标摘要，旧意见不能默套新稿；返工后通过实际依据动作重新固定并回读。create_handoff返回BasisRef，不是SourceRef；通过公开资料任务保存包含Owner、对象、修订、sha256及专业内容的派生快照，下游任务固定原资料与派生快照并完整回读。不同作品分别获权，旧修订和未知操作保持原义。

OpenTimelineIO将媒体引用、时间范围和时率分开，Trelby区分剧本结构与排版。本包独立实现整数帧有理时长及声明式连续性比较，不复制GPL源码，不声称完整OTIO或drop-frame兼容。
