# Skill与机器接续

包内hetu-script-supervisor由河图动态发现，不创建Codex插件、独立MCP服务器或客户端工具名。安装和启用后重新读取活动包摘要、capabilities与skills.read；旧能力绑定不得继续使用。业务无需启动桌面。

默认旅程：读取固定剧本 → 故事日和镜次 → 固定条次与观察 → 明确比较关系 → 处理不一致或未知 → 固定剪辑选择 → 新稿复核 → 场记本与接续。先读已有工程、固定作品及意见，不新建另一份演示工程替代接续。方法由Skill维护，确定性规则由专业后端执行。

场次故事日、场景、人物及镜次明确；条次记录只追加，mode分为人工记录与模拟。入出帧使用整数和精确有理帧率，不以毫秒近似代替时间码；不支持drop-frame时间码换算。连续性观察按角色或道具、类别、状态位置及入出分别记录；比较绑定确切两条和明确匹配项，缺观察返回unknown，允许作者明确有意变化并说明。剪辑选择固定当前场次镜次及条次组合摘要，剧本或镜次改变后旧选择待复核；不把选择记为宿主素材采用。已记录条次及旧观察不覆盖，新证据追加。

每阶段保存并回读固定修订，create_handoff记录依据、目标与未解决问题。其他插件根据实际安装能力独立发现，通过固定专业引用组合。未知先回读，正文采纳、定稿、内容外发与费用按作者确切决定执行。

SKILL.md作为精炼方法入口，references/workflows.md提供专业方法与反例，operations.md从正式清单生成。专业清单由本仓库维护，宿主40只导航动态入口。
