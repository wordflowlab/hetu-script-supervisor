# 场记工作台

> 让固定剧本、镜次条次、连续性观察和剪辑选择能够逐项回读、比较和接续。

## 简介

河图洛书的独立创作插件，由外部Codex通过河图CLI／MCP读取包内Skill并操作。制作筹备拥有资源与计划，导演布景台拥有空间与机位，本包拥有条次及连续性记录；真实文件仍归宿主素材。没有实拍设备控制、自动识别穿帮、影片制作完成认证、外部发送或发布。

## 快速上手

开发需要Node.js 25，安装与验收基线为河图0.12.6。

```bash
npm ci
npm run build
npm run check
npm run test:unit
npm run package
```

## 边界

专业成果沿固定来源与修订接续，正文采纳、定稿、费用和外发独立决定。发行及实际验收范围见[实施记录](docs/08-实施计划与验收记录.md)。
